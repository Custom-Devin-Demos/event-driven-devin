GeForce NOW on iOS

The GeForce NOW client for this demo is a native SwiftUI app. There is no web or Android build: it runs on the iOS simulator from a macOS machine with Xcode 16 or later.

Clone and bootstrap

Check out Custom-Devin-Demos/nvidia-geforce-now-demo-app and run scripts/bootstrap-macos.sh to install XcodeGen and generate App/GeForceNOW.xcodeproj.

Build, test, launch

scripts/verify-ios.sh builds the app, runs the XCTest suites, and boots it on an iPhone simulator. Add RECORD=1 to capture a recording.

Sign in and play

Sign in with the email you use for Devin, browse Home or Games, open a title and tap Play now. Ultimate is the default membership; switch tiers under Membership.

Incident reporting

When Play cannot reserve a rig the app shows a "couldn’t start your session" card and posts a report to POST /api/315f52fe/ios/error on this host, which raises the Slack alert and Devin session for the NVIDIA workspace.

git clone https://github.com/Custom-Devin-Demos/nvidia-geforce-now-demo-app.git
cd nvidia-geforce-now-demo-app
scripts/bootstrap-macos.sh         # xcodegen -> App/GeForceNOW.xcodeproj
scripts/verify-ios.sh              # xcodebuild test + simulator launch (RECORD=1 to record)
(cd Core && swift test)            # Foundation-only domain package; also runs on Linux
Demo identity: not set — on iOS the app uses the email typed at sign-in; on this hub, alerts are raised for the Devin user selected on the demo hub.
