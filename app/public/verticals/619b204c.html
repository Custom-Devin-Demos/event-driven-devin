How this interface works

Every night at 02:00 the Digital Fulfillment Interface picks up booked software orders from the ERP and sends them to the license service, which issues the entitlement (the key that switches the software on at the hospital). Orders on a business hold, like a trade compliance hold, are skipped on purpose. This console only reads from the ERP; changes go through a pull request and IT approval.
