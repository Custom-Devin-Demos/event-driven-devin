イベントの説明

概要

Kanda.js は、神田周辺で月に一度ゆるく集まる Web フロントエンドの勉強会です。第31回のテーマは「可観測性（Observability）」。ブラウザで起きていることを、ログ・メトリクス・トレースの3つの視点から見える化する方法を、ハンズオン形式で学びます。

初参加の方も大歓迎です。前半はセッション、後半はもくもくタイムと LT の時間です。

こんな方におすすめ

  • フロントエンドのパフォーマンス問題を「体感」ではなく「数字」で説明したい方
  • Core Web Vitals や RUM（Real User Monitoring）をこれから導入したい方
  • フロントエンドとバックエンドのトレースをつなげて障害調査をしたい方
