イベントの説明

概要

Shibuya.dev は渋谷周辺のエンジニアが集まる勉強会コミュニティです。第 42 回は LLM を使ったアプリケーション開発のハンズオンを行います。簡単な RAG アプリをゼロから組み上げ、最後に評価の考え方までを一通り体験します。

タイムテーブル

13:30受付開始
14:00オープニング・環境確認
14:15ハンズオン第 1 部：ドキュメント取り込みと検索
15:30休憩
15:45ハンズオン第 2 部：回答生成と評価
16:30LT（5 分 × 5 本）
17:00終了・懇親会（会場参加のみ、自由参加）

対象者

  • Python の基本的な文法が分かる方
  • LLM アプリ開発に興味がある方（経験は問いません）
  • 初参加の方も歓迎します

持ち物

  • ノート PC（Python 3.11 以上がインストールされていること）
  • 各種 API キーは当日の案内に従って発行します
